# E-Commerce-Dashboard-WebApp

A modern, responsive e-commerce dashboard built with React and TailwindCSS. This dashboard features a professional light/dark theme, KPI cards, interactive charts, and a clean, modern UI inspired by Aurora Slate design principles.

## Features

- Fully responsive layout for desktop and mobile
- Dark and light mode support
- Sidebar navigation with slide-over mobile menu
- KPI cards and charts for sales, revenue, products, and customers
- Header with search, notifications, user avatar, and theme toggle
- Footer with custom info
- Modern TailwindCSS styling with rounded corners and shadows
- Smooth transitions and hover effects

## Technologies Used

- React
- TailwindCSS
- React Router
- Recharts (for charts)
- React Icons
